# Yuncheng Wu — academic homepage

A minimal, responsive academic homepage inspired by [Jon Barron's homepage](https://jonbarron.info/), built with Jekyll and the GitHub Pages dependency bundle. The review branch is `redesign/jon-barron`; production remains on `main` until the owner approves and merges a PR.

## Preview the review branch

A separate owner-private online preview is available at <https://yuncheng-homepage-review-20261027.classycharm16385.chatgpt.site>. Sign in with the same account used for Codex. It serves the verified Actions build from this review branch and does not change the production homepage. This is a saved review snapshot; after future source changes, rebuild and refresh the preview.

Draft PR: <https://github.com/lemonviv/lemonviv.github.io/pull/1>.

```sh
git clone --branch redesign/jon-barron https://github.com/lemonviv/lemonviv.github.io.git
cd lemonviv.github.io
bundle install
bundle exec jekyll serve --host 127.0.0.1
```

The committed `.ruby-version` selects Ruby 3.3 and `Gemfile.lock` records the dependencies verified by Actions. Use Ruby 3.3, then visit <http://127.0.0.1:4000>. This is a local preview and does not change GitHub Pages.

Alternatively, open the branch's **Build review preview** run in GitHub Actions. Download the **homepage-preview** artifact, extract it, and run `python3 -m http.server 8000` inside that folder. Visit <http://localhost:8000>. The artifact contains the built website, so Ruby is unnecessary. GitHub login is required to download Actions artifacts; they expire after 30 days and can be regenerated by rerunning the workflow.

The workflow has only `contents: read`, builds with the actual GitHub Pages gems, checks the output and a `/review` base path, and uploads a preview artifact. It contains no Pages deployment job, deployment credentials, `pages: write`, or production branch writes. Do not change the repository's Pages source to this review branch to preview it.

## Maintain content

- Biography: `_includes/about.md`; research interests: `_includes/research.md`.
- News: `_data/news.yml`, newest first. The first 10 items appear initially; earlier items stay available under **Earlier news** without requiring JavaScript.
- Publications: `_data/publications.yml`. All records remain visible without thumbnails; missing PDFs render plain titles without empty links.
- Patents, teaching, services, talks and awards: the existing files in `_includes/`.
- Contact/profile links and metadata: `_config.yml`.
- Presentation: `_layouts/homepage.html`, `index.html`, `assets/css/academic.css`.

The top-right Menu links to each section. Native HTML disclosures work without JavaScript; the small navigation script adds Escape, outside-click dismissal and closing after navigation. The layout respects reduced motion and includes keyboard focus states and a skip link.

## Verify

```sh
bundle exec jekyll build
bundle exec ruby tests/verify_site.rb
bundle exec jekyll build --baseurl /review --destination /tmp/homepage-review
bundle exec ruby tests/verify_site.rb /tmp/homepage-review /review
```

Checks cover section anchors, all news and publication text/links, preserved list entries, no publication images, no empty links, canonical metadata, and local asset resolution.
