# Academic Homepage Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement these tasks in this session.

**Goal:** Deliver the requested Jon Barron style homepage on a review branch without changing the main site.

**Architecture:** Keep Jekyll and its content includes, move biography/research/news into reusable content sources, and replace the layout with semantic HTML and a small stylesheet. Native disclosures provide progressive enhancement.

**Tech Stack:** GitHub Pages, Jekyll, Liquid, Kramdown, CSS, vanilla JavaScript, Ruby/Nokogiri verification.

**Spec:** docs/superpowers/specs/2026-10-27-homepage-design.md

## Global Constraints
- Work only on redesign/jon-barron; no main writes, merges, or production deployments.
- Preserve all existing content and publication data; no paper thumbnails.
- Show exactly the newest 10 news items initially; retain access to all 18 existing items.
- Keep Publications, Patents, Teaching, Professional Services, Invited Talks, Awards and their anchors.

## Review Focus
- Missing PDF: accepted papers must remain readable without empty links.
- JavaScript disabled: menu and news archive remain usable.
- Mobile/zoom: long paper titles and email must wrap without horizontal overflow.
- Subpath previews: assets resolve with a nonempty Jekyll baseurl.
- Production safety: branch build uploads an artifact and cannot deploy Pages.
