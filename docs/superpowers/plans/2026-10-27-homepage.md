> **For agentic workers:** Use superpowers:executing-plans to implement these tasks in this session.

**Architecture:** Keep Jekyll and its content includes, move biography/research/news into reusable content sources, and replace the layout with semantic HTML and a small stylesheet. Native disclosures provide progressive enhancement.

**Tech Stack:** GitHub Pages, Jekyll, Liquid, Kramdown, CSS, vanilla JavaScript, Ruby/Nokogiri verification.

**Spec:** docs/superpowers/specs/2026-10-27-homepage-design.md

- Work only on redesign/jon-barron; no main writes, merges, or production deployments.
